PROJETO PESSOAL · EM DESENVOLVIMENTO

DevStudy

Aplicativo web para organizar os estudos: anotações, matérias do curso de ADS, exercícios corrigidos pelo servidor, flashcards com repetição espaçada, metas semanais e cronômetro Pomodoro. Cada pessoa tem sua própria conta e seus próprios dados.

O que pratiquei: Desenvolvimento web com Flask, banco SQLite, contas com senha criptografada, validação de dados e testes automatizados com pytest.
Python Flask SQLite HTML5 CSS3 pytest Git

PROJETO ACADÊMICO EM DUPLA · EM DESENVOLVIMENTO

AutoParK

Sistema de gerenciamento de estacionamento feito em dupla para a disciplina de Banco de Dados. Controla entrada e saída de veículos, vagas, mensalistas e o fechamento do caixa, calculando o valor pelo tempo de permanência.

O que pratiquei: Modelagem de banco de dados, consultas SQL com JOIN, GROUP BY e HAVING, regras de integridade no banco e trabalho em equipe com Git e GitHub.
MySQL SQL Python Flask PHP Git
